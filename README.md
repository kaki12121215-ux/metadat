# Metadat

Marcos con los datos de cada foto. Webapp instalable (PWA) para iPhone.

- Lee los metadatos (EXIF) de la foto en el propio móvil.
- 30 marcos en claro y oscuro, 10 películas, 8 ajustes.
- Herramientas: lote, privacidad, hoja de contactos, fotómetro, carretes, mi equipo, carrusel, composición y recetas.

Versión 1.0.0 · https://kaki12121215-ux.github.io/metadat/
